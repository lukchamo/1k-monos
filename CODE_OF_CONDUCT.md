# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En corto: sé amable, asume buena fe, critica las ideas y no a las personas, y no acoses a nadie. Quien mantenga el proyecto puede editar o retirar comentarios, commits e issues que no lo cumplan.

Para avisar de un problema de conducta, usa el aviso privado de seguridad del repositorio (pestaña Security → Report a vulnerability) indicando que es un asunto de conducta.
